# MemoPad テスト観点表

## 1. ID命名規則

テスト観点IDは、機能と画面または確認領域ごとに採番する。

| 形式 | 内容 | 例 |
| --- | --- | --- |
| `VP-{AREA}-{NNN}` | 単一画面または単一機能の観点 | `VP-LOGIN-001` |
| `VP-{AREA}-{SCREEN}-{NNN}` | 機能内の画面別観点 | `VP-MEMO-LIST-001` |
| `VP-COMMON-{AREA}-{NNN}` | 共通観点 | `VP-COMMON-API-001` |

複数画面にまたがる観点は、原則として画面ごとに分割する。画面に閉じない共通仕様は `COMMON` 系IDで管理する。

## 3. テスト実施時の共通前提

- テスト環境は Windows 10 または Windows 11、Node.js LTS、React + Vite、Express、SQLite + better-sqlite3 とする。
- React画面は `http://localhost:5173`、Express APIは `http://localhost:3001` を使用する。
- DBは `data/memo.db`、添付ファイルは `uploads/attachments/`、画像は `uploads/images/` を使用する。
- タイムゾーンは `Asia/Tokyo` とする。
- テストユーザーとして、管理者、一般ユーザー、無効化ユーザーを準備する。
- 本番DBを使用しない。
- テストデータには識別可能な接頭辞を付ける。
- テスト結果には、テストケースID、機能名、種別、重要度、前提条件、操作手順、期待結果、実際の結果、HTTPステータス、DB確認結果、合否、備考を記録する。
