# 変更方針確認観点

## 1. 目的

提示された機能一覧を `docs/requirements.md` に反映する前に、要件として不足・曖昧・補完が必要な点を確認する。

本ドキュメントは方針確認用であり、コード実装は行わない。

## 2. 全体確認観点

| 観点 | 確認内容 | 補完方針 |
| --- | --- | --- |
| 要件の範囲 | 25 項目の機能一覧をすべて実装対象とするか | すべて実装対象として扱う |
| 機能の優先度 | 基本メモ機能と追加機能を同時に扱うか | 基本 CRUD、認証、検索を先に実装し、追加機能を段階実装する |
| QA 演習観点 | 正常系、異常系、境界値が作れるか | 入力条件、エラー文言、件数上限、権限制御を明文化する |
| 表示文言 | 要件にある文言を画面表示と一致させるか | エラーメッセージ、成功メッセージは固定文言として管理する |
| データ保持 | 削除や下書きをどう保持するか | 削除は論理削除、自動保存は下書きテーブルで管理する |

## 4. 自動補完候補

| 補完候補 | 理由 | 方針 |
| --- | --- | --- |
| 存在しないメモの扱い | 詳細・編集・削除で直接 URL アクセスの確認が必要 | 「指定されたメモは存在しません。」を追加する |
| 権限なしアクセスの扱い | 一般ユーザーのアクセス制御確認が必要 | アクセス不可メッセージを定義する |
| メールアドレス一意制約 | ユーザー管理で重複確認が必要 | システム内で一意とする |
| 画像の編集操作 | アップロード後の削除・差し替え確認が必要 | 編集画面で追加・削除可能とする |
| 下書き復元 | 自動保存の完了条件が曖昧 | 下書きがある場合に復元できるようにする |
| 削除方式 | 削除済みを一覧・検索に出さない要件がある | 論理削除を採用する |

## 5. 方針確認後の更新対象

方針確認後、必要に応じて以下を更新する。

| ファイル | 更新内容 |
| --- | --- |
| `docs/requirements.md` | 機能一覧、補完要件、確認観点を反映する |
| `docs/implementation-plan.md` | 要件変更に合わせて実装順序や API 方針を更新する |

コード実装は、要件と方針の確認後に行う。

## 6. ユーザー管理・権限管理 実装前確認観点

### 6.1 対象範囲

今回の実装対象は以下とする。

- ユーザー一覧
- ユーザー作成
- ユーザー編集
- ユーザー無効化
- 管理者 / 一般ユーザーの画面制御

管理者はすべての画面と操作を許可する。画面制御として詳細に確認する対象は一般ユーザーのみとする。

### 6.2 基本方針

| 観点 | 確認内容 | 方針 |
| --- | --- | --- |
| 管理者の扱い | 管理者に画面制限を設けるか | 設けない。すべての画面を許可する |
| 一般ユーザーの扱い | 一般ユーザーに制限を設けるか | ユーザー管理系画面は不許可、自分のメモのみ操作可能とする |
| フロント制御 | 画面上のリンクやボタンをどう制御するか | 一般ユーザーにはユーザー管理導線を表示しない |
| API 制御 | 直接 API を呼ばれた場合をどう扱うか | サーバ側でも必ず権限チェックする |
| 権限エラー | 権限がない場合の表示 | 「アクセス権限がありません。」を表示し、メモ一覧へ戻す |

### 9.8 API 確認観点

| API | 確認内容 | 期待結果 |
| --- | --- | --- |
| `POST /api/todos` | メモ作成時にファイル・画像を登録する | メモとファイルメタ情報を保存する |
| `PUT /api/todos/:id` | メモ編集時にファイル・画像を追加する | 既存ファイルを残し、新規分を追加する |

`multipart/form-data` を使うため、Express 側ではアップロード処理用パッケージの追加が必要になる。候補は `multer` とする。

### 9.12 実装前の決定事項

| 項目 | 推奨方針 |
| --- | --- |
| アップロード処理 | `multer` を追加して `multipart/form-data` を扱う |
| 保存先 | `uploads/attachments`、`uploads/images` |
| DB テーブル | `memo_files` に添付・画像をまとめて保存 |
| 削除方式 | 論理削除 |
| 添付ファイル上限 | 5 件、1 ファイル 10 MB |

| 拡張子判定 | 小文字化して判定 |
| 自動保存対象 | ファイル実体は対象外。手動保存時のみ保存 |
| ダウンロード | `GET /api/files/:fileId/download` で権限制御して返却 |
