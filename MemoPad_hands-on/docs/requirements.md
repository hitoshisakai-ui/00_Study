# MemoPad 要件定義

## 1. 概要

MemoPad は、ユーザーがブラウザ上でメモを作成・閲覧・編集・削除できる QA 演習用の簡易 Web アプリケーションである。

基本機能に加えて、ログイン、ユーザー管理、権限管理、ファイル添付、画像アップロード、タグ、お気に入り、自動保存、ページング、並び替え、同時編集制御を実装対象とする。

## 2. 機能一覧

### 2.1 メモ一覧表示

- 登録済みメモを一覧表示できる。
- 初期表示では更新日時の新しい順で表示する。
- 各メモにはタイトル、本文冒頭 50 文字、更新日時、詳細ボタン、編集ボタン、削除ボタンを表示する。
- メモが 1 件も存在しない場合は「メモが登録されていません。」と表示する。
- 削除済みメモは一覧に表示しない。

### 2.2 メモ新規作成

- 一覧画面の「新規作成」ボタンから作成画面へ遷移できる。
- タイトルと本文を入力してメモを登録できる。
- 登録成功時は「メモを登録しました。」と表示して一覧画面へ遷移する。
- 入力エラーがある場合は画面遷移せず、該当項目の下にエラーを表示する。
- 複数のエラーがある場合は、すべて表示する。

### 2.3 メモ詳細表示

- 詳細画面ではタイトル、本文、作成日時、更新日時を表示する。
- 詳細画面から編集、削除、一覧へ戻る操作ができる。
- 削除済み、または存在しないメモの URL へ直接アクセスした場合は「指定されたメモは存在しません。」と表示する。

### 2.4 メモ編集

- 登録済みのタイトルと本文を初期表示する。
- 入力ルールは新規作成と同じとする。
- 更新成功時は「メモを更新しました。」と表示する。
- 更新時はメモ ID と作成日時を変更しない。
- 更新時は更新日時を更新する。

### 2.5 メモ削除

- 削除ボタン押下時は、すぐに削除せず確認画面を表示する。
- 確認画面には「このメモを削除しますか？」と表示する。
- 選択肢は「削除する」「キャンセル」とする。
- 削除成功後は「メモを削除しました。」と表示して一覧画面へ戻る。
- 削除済みメモは一覧・検索結果に表示しない。

### 2.6 メモ検索

- 一覧画面に検索欄を設ける。
- 検索対象はタイトルと本文とする。
- 入力した文字列を含むメモを表示する。
- 英字については大文字・小文字を区別しない。
- 検索結果が 0 件の場合は「条件に一致するメモがありません。」と表示する。
- 検索欄が空の状態で検索した場合は、すべてのメモを表示する。

### 2.7 入力チェック

#### タイトル

- タイトルは必須とする。
- 半角・全角スペースのみの場合は登録・更新できない。
- 101 文字以上の場合は登録・更新できない。
- 未入力・空白のみの場合は「タイトルを入力してください。」と表示する。
- 101 文字以上の場合は「タイトルは100文字以内で入力してください。」と表示する。

#### 本文

- 本文は必須とする。
- スペースのみ、改行のみ、スペースと改行のみの場合は登録・更新できない。
- 2,001 文字以上の場合は登録・更新できない。
- 未入力・空白のみの場合は「本文を入力してください。」と表示する。
- 2,001 文字以上の場合は「本文は2000文字以内で入力してください。」と表示する。

### 2.8 入力可能文字・HTML 無害化

- 日本語、半角・全角英数字、記号、絵文字、改行を入力可能とする。
- HTML タグに相当する文字列も入力可能とする。
- 入力された HTML や JavaScript は実行せず、文字列として表示する。
- 例として `<script>alert(1)</script>` は文字列として表示する。

### 2.9 キャンセル確認

- 新規作成・編集画面には「キャンセル」ボタンを表示する。
- 入力内容を変更している場合、キャンセル時に「入力内容は保存されていません。破棄しますか？」と確認する。
- 選択肢は「破棄する」「編集を続ける」とする。

### 2.10 ログイン

- ユーザーはユーザー ID とパスワードでログインできる。
- ユーザー ID はシステム内で一意とする。
- ユーザー ID の大文字・小文字は区別しない。
- ログイン成功後はメモ一覧画面へ遷移する。
- ログイン失敗時は「ユーザーIDまたはパスワードが正しくありません。」と表示する。
- 未ログイン状態ではメモ一覧・詳細・作成・編集・削除画面にアクセスできない。
- 未ログイン状態で保護された画面へアクセスした場合はログイン画面へリダイレクトする。
- ログアウトできる。
- ログアウト後はログイン画面へ遷移する。

### 2.11 ログイン入力チェック

#### ユーザー ID

- ユーザー ID は必須とする。
- ユーザー ID は 4 文字以上 20 文字以内とする。
- 使用可能文字は半角英数字、ハイフン、アンダースコアとする。
- 未入力の場合は「ユーザーIDを入力してください。」と表示する。
- 形式不正の場合は「ユーザーIDは半角英数字、ハイフン、アンダースコアで入力してください。」と表示する。
- 4 文字未満または 21 文字以上の場合は「ユーザーIDは4文字以上20文字以内で入力してください。」と表示する。

#### パスワード

- パスワードは必須とする。
- パスワードは 8 文字以上 64 文字以内とする。
- 未入力の場合は「パスワードを入力してください。」と表示する。
- 8 文字未満または 65 文字以上の場合は「パスワードは8文字以上64文字以内で入力してください。」と表示する。

### 2.12 ユーザー管理

- 管理者はユーザーを新規作成・一覧表示・編集・無効化できる。
- ユーザー情報としてユーザー ID、表示名、メールアドレス、パスワード、権限、状態、作成日時、更新日時を管理する。
- メールアドレスはシステム内で一意とする。
- 無効化されたユーザーはログインできない。
- 一般ユーザーはユーザー管理画面にアクセスできない。

### 2.13 権限管理

- 権限は「管理者」「一般ユーザー」の 2 種類とする。
- 管理者は全ユーザーのメモを閲覧・編集・削除できる。
- 一般ユーザーは自分が作成したメモのみ閲覧・編集・削除できる。
- 権限がない画面またはメモへアクセスした場合は、アクセス不可であることを表示する。

### 2.14 ファイル添付

- メモには任意でファイルを添付できる。
- 1 メモにつき最大 5 ファイルまで添付できる。
- 1 ファイルの最大サイズは 10 MB とする。
- 添付可能な拡張子は `pdf`, `txt`, `csv`, `docx`, `xlsx` とする。
- 添付ファイルは詳細画面からダウンロードできる。
- 編集画面で添付ファイルの追加・削除ができる。

### 2.15 画像アップロード

- メモには画像をアップロードできる。
- 対応形式は `jpg`, `jpeg`, `png`, `gif`, `webp` とする。
- 1 画像の最大サイズは 5 MB とする。
- 画像は 1 メモにつき最大 10 枚まで登録できる。
- アップロード画像は詳細画面でプレビュー表示する。
- 編集画面で画像の追加・削除ができる。

### 2.16 タグ

- メモにはタグを付与できる。
- 1 メモにつき最大 10 個までタグを付与できる。
- タグ名は 1 文字以上 30 文字以内とする。
- 同一メモ内で同じタグを重複登録できない。
- タグによる絞り込み検索ができる。

### 2.17 お気に入り

- メモをお気に入り登録・解除できる。
- お気に入り済みメモのみを一覧表示できる。
- お気に入り状態はユーザーごとに保持する。

### 2.18 自動保存

- 新規作成・編集画面では入力内容を自動保存する。
- 入力変更後、3 秒間操作がない場合に下書き保存する。
- 自動保存成功時は「下書きを保存しました。」と表示する。
- 自動保存に失敗しても手動登録・更新は継続可能とする。
- 自動保存された下書きがある場合、作成・編集画面で復元できる。

### 2.19 ページング

- メモ一覧はページング表示できる。
- 1 ページあたりの表示件数は 10 件、25 件、50 件から選択できる。
- 初期表示件数は 10 件とする。
- 検索、タグ絞り込み、お気に入り絞り込み結果にもページングを適用する。

### 2.20 並び替え

- メモ一覧は並び替えできる。
- 並び替え対象は作成日時、更新日時、タイトルとする。
- 昇順・降順を選択できる。
- 初期表示は更新日時の降順とする。

### 2.21 同時編集制御

- 複数ユーザーが同じメモを編集する場合、更新競合を検知する。
- 編集開始時点の更新日時と保存時点の更新日時が異なる場合は更新できない。
- 競合時は「他のユーザーによって更新されています。内容を確認して再度保存してください。」と表示する。
- 競合発生時は入力中の内容を失わず保持する。

### 2.22 二重登録・二重更新防止

- 登録・更新処理中はボタンを押せない状態にする。
- 登録ボタンを連続して押しても、同じメモが複数登録されてはならない。
- 更新ボタンを連続して押しても、不整合な更新が発生してはならない。

### 2.23 エラー処理

- 登録・更新・削除などでサーバー側のエラーが発生した場合は「処理中にエラーが発生しました。時間をおいて再度お試しください。」と表示する。
- 登録・更新に失敗した場合は入力内容を保持する。
- 通信できなかった場合は「通信に失敗しました。ネットワーク接続を確認してください。」と表示する。
- エラー発生時は登録・更新・削除が成功したものとして扱わない。

### 2.24 日時表示

- 作成日時・更新日時は `YYYY/MM/DD HH:mm:ss` 形式で表示する。
- 例は `2026/08/12 15:30:45` とする。

## 3. データ要件

### 3.1 メモ

| 項目 | 内容 |
| --- | --- |
| メモ ID | システムが自動採番する |
| 作成者ユーザー ID | メモを作成したユーザーの ID |
| タイトル | メモのタイトル |
| 本文 | メモ本文 |
| 作成日時 | 初回登録日時 |
| 更新日時 | 最終更新日時 |
| 削除日時 | 削除日時。未削除の場合は未設定 |

### 3.2 ユーザー

| 項目 | 内容 |
| --- | --- |
| ユーザー ID | ログインに使用する一意の ID |
| 表示名 | 画面表示用の名前 |
| メールアドレス | ユーザーのメールアドレス |
| パスワード | ログイン認証用のパスワード |
| 権限 | 管理者または一般ユーザー |
| 状態 | 有効または無効 |
| 作成日時 | 初回登録日時 |
| 更新日時 | 最終更新日時 |

### 3.3 添付ファイル

| 項目 | 内容 |
| --- | --- |
| ファイル ID | システムが自動採番する |
| メモ ID | 紐づくメモの ID |
| ファイル名 | アップロード時のファイル名 |
| 保存パス | サーバー上の保存先 |
| MIME タイプ | ファイルの MIME タイプ |
| サイズ | ファイルサイズ |
| 作成日時 | アップロード日時 |

### 3.4 画像

| 項目 | 内容 |
| --- | --- |
| 画像 ID | システムが自動採番する |
| メモ ID | 紐づくメモの ID |
| ファイル名 | アップロード時のファイル名 |
| 保存パス | サーバー上の保存先 |
| MIME タイプ | 画像の MIME タイプ |
| サイズ | 画像サイズ |
| 作成日時 | アップロード日時 |

### 3.5 タグ

| 項目 | 内容 |
| --- | --- |
| タグ ID | システムが自動採番する |
| タグ名 | タグ表示名 |
| 作成日時 | 初回登録日時 |

### 3.6 メモタグ

| 項目 | 内容 |
| --- | --- |
| メモ ID | 紐づくメモの ID |
| タグ ID | 紐づくタグの ID |

### 3.7 お気に入り

| 項目 | 内容 |
| --- | --- |
| ユーザー ID | お気に入り登録したユーザーの ID |
| メモ ID | お気に入り対象のメモ ID |
| 作成日時 | お気に入り登録日時 |

### 3.8 下書き

| 項目 | 内容 |
| --- | --- |
| 下書き ID | システムが自動採番する |
| ユーザー ID | 下書きを保持するユーザーの ID |
| メモ ID | 編集中メモの ID。新規作成の場合は未設定 |
| タイトル | 自動保存されたタイトル |
| 本文 | 自動保存された本文 |
| 保存日時 | 最終自動保存日時 |

## 4. 主な境界値

### 4.1 メモ

| 対象 | 境界値 |
| --- | --- |
| タイトル | 0 文字、1 文字、100 文字、101 文字 |
| 本文 | 0 文字、1 文字、2,000 文字、2,001 文字 |

### 4.2 ログイン

| 対象 | 境界値 |
| --- | --- |
| ユーザー ID | 0 文字、1 文字、3 文字、4 文字、20 文字、21 文字 |
| パスワード | 0 文字、1 文字、7 文字、8 文字、64 文字、65 文字 |

### 4.3 ファイル・画像

| 対象 | 境界値 |
| --- | --- |
| 添付ファイル数 | 0 件、1 件、5 件、6 件 |
| 添付ファイルサイズ | 0 byte、1 byte、10 MB、10 MB 超過 |
| 画像数 | 0 件、1 件、10 件、11 件 |
| 画像サイズ | 0 byte、1 byte、5 MB、5 MB 超過 |

### 4.4 タグ

| 対象 | 境界値 |
| --- | --- |
| タグ数 | 0 個、1 個、10 個、11 個 |
| タグ名 | 0 文字、1 文字、30 文字、31 文字 |
